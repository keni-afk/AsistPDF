AsistPDF Pro 📄⚡
Sistema desarrollado en Python para generar documentos PDF profesionales mediante una interfaz moderna, rápida e intuitiva.

# 🚀 Descargar ejecutable

1. Ir a la sección **Releases**
2. Descargar `AsistPDF.exe`
3. Ejecutar el archivo con doble clic

No requiere instalar Python.

# 💻 Ejecutar en modo desarrollador

Instalar dependencias:
```bash
pip install -r requirements.txt
```

Ejecutar:
```bash
python app/piplup.py
```


# 📦 Generar EXE
```bash
pyinstaller --onefile --windowed --name AsistPDF app/piplup.py
```

El ejecutable se generará en:
```
dist/AsistPDF.exe
```
